This is an original portfolio design inspired by the visual language of modern dark/purple portfolio sites. It does not copy the reference portfolio's content or code.

- Scroll progress indicator

- Direct GitHub links for every featured project
- Downloadable CV
- Animated project artwork
- Custom pointer effect on desktop

## GitHub Pages
1. Create a public repository, e.g. `my-portfolio`.
2. Upload the contents of this folder (not the ZIP itself).
3. Keep the `assets` folder beside `index.html`.
4. Open repository Settings → Pages.
5. Choose Deploy from a branch → `main` → `/ (root)` → Save.
6. GitHub will publish the site.

The CV and profile image are local assets, so the download button and image will work on GitHub Pages.
